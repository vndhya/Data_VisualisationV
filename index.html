PROJECT BACKGROUND

About this dashboard

Project purpose

This COS30045 Data Visualisation project explores Australian hospitalised road injury data through clear and interactive visualisations.

The dashboard is intended to help users examine changes over time and compare the categories available in the selected dataset.

Data preparation

Data preparation is being carried out using KNIME. The process includes inspecting the source tables, selecting relevant columns and checking missing values and data types.

The final visualisations will use verified exports from the cleaned data.

Data source

The project uses hospitalised road injury publications from the Bureau of Infrastructure and Transport Research Economics (BITRE).

The final workbook references, reporting period, population scope and data notes will be added during data integration.

Current limitations

This is an initial website prototype. The summary cards and chart areas currently contain placeholders.

Filter controls are disabled until the relevant data and filtering logic have been connected.
